flowchart LR
  UI[retrieve-v3 / 结果组件]
  ACTION[retrieve-search-actions]
  FIELD[字段缓存服务]
  WORKER[retrieve-search-worker.service]
  WW[WebWorker<br/>fetch + NDJSON/JSON]
  REPO[retrieve-row.repository]
  IDB[(IndexedDB<br/>retrieveRows)]
  CACHE[retrieve-row-cache.service]
  STATE[(Vuex)]
  API[/search/* API]

  UI -->|dispatch 字段/查询| ACTION
  ACTION -->|commit 参数、字段、loading| STATE
  ACTION --> FIELD
  FIELD -->|字段元数据| STATE
  FIELD --> IDB
  ACTION -->|searchStream| WORKER
  WORKER -->|postMessage body/queryKey/startSeq| WW
  WW --> API
  API -->|meta/row/done| WW
  WW -->|批量写入| REPO
  REPO --> IDB
  WW -->|progress meta/rowKeys/result| WORKER
  WORKER -->|元数据、row_keys、total、错误| ACTION
  ACTION -->|commit 结果元数据与 row_keys| STATE
  STATE --> UI
  UI -->|按 row_keys 读取| CACHE
  CACHE --> IDB
  CACHE -->|渲染行 / overlay / 原始行| UI
