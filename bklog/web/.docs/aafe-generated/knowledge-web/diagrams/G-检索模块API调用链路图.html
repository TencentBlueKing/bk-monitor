flowchart TD
  PRELOAD[应用 preload<br/>空间 / 用户 / 全局配置] --> INDEX[GET /search/index_set/]
  INDEX --> FIELD{字段元数据}
  FIELD -->|普通| F1[GET /search/index_set/:id/fields/]
  FIELD -->|联合| F2[unionSearch/unionMapping]
  FIELD -->|场景| F3[POST /search/scene/fields/]
  F1 --> META[normalize fields<br/>field cache + IndexedDB]
  F2 --> META
  F3 --> META
  META --> QUERY{主查询分支}
  QUERY -->|普通单索引| Q1[POST /search/index_set/:id/search/?stream=true]
  QUERY -->|联合索引| Q2[POST /search/index_set/union_search/?stream=true]
  QUERY -->|场景检索| Q3[POST /search/scene/search/?stream=true]
  Q1 --> WORKER[WebWorker<br/>fetch + NDJSON/JSON]
  Q2 --> WORKER
  Q3 --> WORKER
  WORKER --> ROWS[IndexedDB retrieveRows<br/>row_keys + query metadata]
  ROWS --> RESULT[Vuex + 结果组件]
  RESULT --> DERIVED[趋势 / Terms / 上下文 / 实时 / 导出 / Grep / 聚类]
  DERIVED --> NORMAL[普通与联合 API]
  DERIVED --> SCENARIO[场景 API]
  NORMAL --> SERVICES[src/services/retrieve.ts]
  SCENARIO --> SERVICES
