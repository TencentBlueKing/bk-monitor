sequenceDiagram
    participant Browser as 浏览器
    participant HTML as index.html
    participant Loading as bootstrap-loading
    participant Main as main.js
    participant Preload as preload.ts
    participant Store as Vuex Store
    participant HTTP as HTTP Layer
    participant API as Backend API
    participant Router as Vue Router
    participant App as App.tsx

    Browser->>HTML: 加载静态文档壳
    HTML->>Loading: 立即渲染首屏占位<br/>Init resources / Load runtime / Prepare search
    HTML->>Browser: 提供 #app 挂载点
    Note over HTML,Loading: 此时 i18n/Vue 尚未就绪<br/>占位文案保持静态英文

    Browser->>Main: 注入并执行 JS bundle

    rect rgb(240, 248, 255)
        Note over Main: 1. 初始化全局能力
        Main->>Main: 注册全局组件<br/>(JsonFormatWrapper, LogButton, LogIcon)
        Main->>Main: 注册全局 mixin/plugin<br/>(docsLinkMixin, vue-virtual-scroller)
        Main->>Main: 设置 Vue.prototype<br/>($renderHeader, $xss)
    end

    rect rgb(255, 248, 240)
        Note over Main, API: 2. Preload 阶段 (Promise.allSettled 并行)
        Main->>Preload: preload({ http, store })
        par 首屏关键并行请求
            Preload->>API: space/getMySpaceList<br/>(必要时先 indexSet/getSpaceByIndexId)
            Preload->>API: userInfo/getUsername
            Preload->>API: collect/globals
        end
        API-->>Preload: 返回结果
        Preload->>Store: commit(spaceUid, bkBizId, userMeta, globalsData...)
    end

    rect rgb(240, 255, 240)
        Note over Main, App: 3. 创建路由 + 挂载（菜单空闲补齐）
        Main->>Router: getRouter(spaceUid, bkBizId, externalMenu)
        Main->>Store: 若无 topMenu 则写入 DEFAULT_MENU_LISTS
        Main->>App: new Vue({ el:'#app', router, store, i18n })
        App->>Browser: 渲染 App / router-view
        App->>Loading: mounted → fadeOutBootstrapLoading
        Note over Loading: is-leaving 过渡后从 DOM 移除
        Main->>API: requestIdleCallback → meta/menu
        API-->>Store: 异步刷新 topMenu
        Main->>API: requestIdleCallback → meta/getUserGuide
    end

    rect rgb(255, 240, 255)
        Note over Main, API: 4. Development 环境额外步骤
        alt isDevelopment
            Main->>API: meta/getEnvConstant
            API-->>Main: 环境常量
            Main->>Main: 写入 window.FEATURE_TOGGLE 等
            Main->>Main: 再进入 mountedVueInstance
        end
    end
