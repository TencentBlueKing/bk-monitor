## 2. 设计变化

旧版模型是“组件 dispatch → Axios → 完整结果返回 → Vuex 保存结果”。当前模型拆分为：

- Vuex 保存检索状态和结果元数据，不保存大规模完整行数组；
- Worker 负责流式网络读取、NDJSON 解析和批量持久化；
- IndexedDB 保存原始行、渲染元数据和行序号；
- 页面通过 `row_keys` 延迟读取和渲染；
- 查询键、请求 ID、分页序号和活跃查询心跳共同保障竞态安全和缓存回收。
