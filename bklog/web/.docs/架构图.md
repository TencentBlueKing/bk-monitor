## 2. 静态壳层 `index.html` 的设计位置

`index.html` 不是业务页面，而是 **JS/Vue 就绪前的静态壳**，职责边界如下：

| 职责 | 实现要点 |
|---|---|
| 文档元信息 | charset、viewport、favicon、`日志平台 \| 蓝鲸智云` title |
| 挂载锚点 | `#app`，供 `main.js` 创建 Vue 根实例 |
| 首屏占位 | `.bklog-bootstrap-loading` 全屏卡片，避免白屏 |
| 阶段文案 | `Init resources` → `Load runtime` → `Prepare search`，对应静态资源 / 运行时 preload / 检索页准备 |
| 退出时机 | `App.mounted` 调用 `fadeOutBootstrapLoading()`：先给 `#app` 加 `bklog-bootstrap-app-enter`，再给 loading 加 `is-leaving`，约 520ms 后从 DOM 移除 |
| 无 i18n 约束 | 壳层早于 Vue/i18n，文案保持静态英文 |
| 体验细节 | `role="status"` + `aria-live="polite"`；`prefers-reduced-motion` 降级动画；`min-width: 1280px` 与桌面端布局一致 |

它与后续链路的衔接是：

```text
index.html 绘制壳
  -> webpack 注入 JS
  -> main.js 注册全局能力
  -> preload 并行拉 space / userInfo / globals 写入 Vuex
  -> getRouter + mount #app
  -> 淡出 bootstrap-loading
  -> idle 补齐 meta/menu、userGuide
  -> 路由进入 retrieve-hub / retrieve-v3 ...
```

## 3. 设计变化

旧版模型是“组件 dispatch → Axios → 完整结果返回 → Vuex 保存结果”。当前模型拆分为：

- 静态壳与业务运行时分离：`index.html` 只负责首屏占位，`main.js` 负责卸载；
- Vuex 保存检索状态和结果元数据，不保存大规模完整行数组；
- Worker 负责流式网络读取、NDJSON 解析和批量持久化；
- IndexedDB 保存原始行、渲染元数据和行序号；
- 页面通过 `row_keys` 延迟读取和渲染；
- 查询键、请求 ID、分页序号和活跃查询心跳共同保障竞态安全和缓存回收。

## 5. 代码定位

- 静态壳：`bklog/web/index.html`
- 启动编排：`src/main.js`（`fadeOutBootstrapLoading` / `mountedVueInstance`）
- 预加载：`src/preload.ts`
- 页面入口：`src/views/retrieve-hub.tsx`、`src/views/retrieve-v3/index.tsx`
- 初始化编排：`src/views/retrieve-v3/use-app-init.tsx`
- 查询 action：`src/store/actions/retrieve-search-actions.js`
- API 定义：`src/services/retrieve.ts`
- Worker 管理：`src/storage/services/retrieve-search-worker.service.ts`
- Worker 实现：`src/storage/workers/retrieve-search.worker.ts`
- 行仓储：`src/storage/repositories/retrieve-row.repository.ts`
- 行缓存：`src/storage/services/retrieve-row-cache.service.ts`
- 字段缓存：`src/storage/services/retrieve-field-cache.service.ts`
- 数据库：`src/storage/core/db.ts`
