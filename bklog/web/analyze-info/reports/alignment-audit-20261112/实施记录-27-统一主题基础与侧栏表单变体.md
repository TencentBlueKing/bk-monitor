# 统一主题基础与侧栏表单变体

## 本批结果

按统一主题方案完成公共样式入口拆分、语义 Token 映射、按钮尺寸修正及三个侧栏表单变体接入。没有批量替换业务布局，没有修改 V2、接口、表单数据或提交副作用。

这是方案的第一批实现，不是整个 P0–P5 的完成声明：主题边界隔离、Provider 默认配置治理、剩余表格/查询控件迁移及全部模块视觉验收仍需后续批次。

## 已落地结构

路径相对 packages/web-v3：

- src/shared/styles/theme/tdesign-bklog.scss 保持唯一公共入口，原 332 行混合内容拆分为按职责加载的模块。
- tokens.scss：唯一语义变量，基础颜色、字体、尺寸和圆角复用已有 theme.scss Sass 变量。
- tdesign-tokens.scss：只映射 TDesign 变量，不再独立定义第二份品牌值。
- overlay.scss：层级及兼容空态规则；层级管理行为保持原样。
- components/buttons.scss：普通按钮及原生尺寸映射。
- components/actions.scss：Dialog/Drawer 页脚按钮、管理操作按钮的公共 mixin。
- components/overlays.scss、options.scss、display.scss：分别保留原弹层、选项、Tag/Alert 外观规则，不把它们伪装成 Token。
- components/forms.scss：显式 stack、compact、cluster 三种侧栏表单间距变体。
- compat-drawer.scss、management-lists.scss 从公共入口统一加载；删除 legacy-control-styles.ts 和管理页面的分散引入，避免单独加载主题时缺少侧栏规则。

入口同时服务主应用与 monitor-bootstrap，保持现有主题加载机制。没有另建与运行时脱节的配置目录。

## 具体替换

### 按钮

原 `.t-button--size-medium` 未命中原生按钮。改用低优先级的普通尺寸匹配，使业务专用规则仍可覆盖。按钮本体局部设置 xs/xl 对应的尺寸变量，不修改全局 xs/xl，避免影响读取同名尺寸的其他组件。

浏览器实测小/普通/大号分别 26/32/38px，字号 12/14/16px。普通表格文字按钮仍由管理列表或业务专用规则处理。

### 管理操作与侧栏

管理列表和兼容抽屉重复的字号、最小宽度规则改用公共 mixin。ES Drawer 的重复 body padding 规则移入公共兼容抽屉，内容仍由业务组件拥有。

初次合成页面验证暴露了侧栏样式缺少引入：标题仍为 56px、body padding 16px。调整为统一入口后，实测恢复标题 52px、body padding 0。不能仅编译 Sass 判断样式已生效。

### 表单变体

- Grok：stack，项间距 24px，最后一项底部 0，Form 全宽与 min-width 0；删除原 Grok 内部 Form 结构覆盖。
- 归档仓库：compact，项前间距 12px、项后 0；保留仓库卡片、选择控件宽度和原表单 padding。
- ES 配置：cluster，首项前 18px，相邻项前 8px、项后 0；保留业务特殊行、说明、字段及内联例外。

只合并重复结构，不把三种既有间距强行统一。当前业务 SCSS 内类名引用由 500 降为 495；这是谨慎替换的首批，不以文件拆分后的总数宣称大幅消除覆盖。

## 公共规则新增检查

新增 tools/check-tdesign-style-drift.mjs，运行方式：`node tools/check-tdesign-style-drift.mjs`。

默认对比审计时工程清单，检查 features 下 SCSS/Vue style 新增的 TDesign 类名及 important 数量。当前输出 NO_NEW_COUPLING。它是提示性门禁，不是全面 CSS 分析，也不能检测原有类名内部新增的属性、TS 字符串和内联样式。

新增工具只读取源码元数据，不接触截图、接口数据或运行日志。基线不自动覆盖，避免把新增覆盖默认为已接受。
