# 实施记录 11：下拉骨架行高与选中背景宽度

## 根因与修复

条件值浮层此前同时存在两个尺寸问题：Tippy 外框按内容居中，内层 `.condition-value-options` 又固定为 314px。仅让外框与输入框等宽后，内层列表及选中背景仍停留在 314px，因此出现右侧大面积留白。

本批将完整尺寸链一起修正：

- 使用 `shared/global/dropdown-width.ts` 中的 Popper modifier，在每次布局计算时读取 reference 宽度，更新弹层外框；使用 bottom-start 左对齐，保留原有边界溢出与翻转规则。
- 条件操作符、条件值和普通标签选择浮层共用同样的宽度规则。Tippy 内层取消额外 padding，列表宽度 100%，选项使用 border-box 并禁止纵向挤压。条件值选中、hover、键盘高亮继续沿用原来的状态和颜色。
- 场景联想列表相对所属输入框定位，left=0、width=100%，避免撑开表单或依赖内容宽度。
- 新增 `DropdownLoadingSkeleton`，默认 3 项，每项高 24px、宽 100%；允许通过 rows/itemHeight 配置。骨架条在行内垂直居中。分页追加只显示 1 个骨架项。
- 条件值、场景联想和标签选择加载时直接渲染专用骨架，不再把通用居中三条指示器叠到“暂无数据”之上。空态仅在请求结束且无数据时展示。场景联想仍保留透明点击阻挡层，加载中不能误选已有行。已有选项与分页请求、选择/删除、焦点及提交逻辑保持原样。

V2 及已有页面级检索、图表、聚类骨架不修改。
