- 已移除根工程、web-v3 的 Vuex 4 开发依赖和对应 peer 规则、锁文件 importer/package/snapshot。保留第三方 `@blueking/log-web` 的 Vuex 3 传递依赖；不影响 V2 对照和封版 V1。
- 新建 `src/app/state/domains/collection-store.ts`、`globals-store.ts`。原生 Pinia 平铺状态、具名 action 是这两个域的唯一状态来源，保留原有替换、合并、权限置空等语义。
- 迁移采集域 23 个业务文件 38 处调用、全局域 35 个文件 35 处调用。这里是两次迁移的计数，文件交集不能重复作为总覆盖率。
- 为尚未迁移的调用保留临时兼容视图，所有读写指向同一个原生 `$state`，没有第二份状态。多 Pinia 实例隔离、具名 action 生命周期、旧新调用共享状态有测试。
- **未完成**：application/retrieve 仍运行旧定义转换；Options API map helpers、部分跨域/字符串调用、`$store` 和 Monitor 消费者仍需迁移。尚未删除 state-runtime/domain-store，不能宣称完成 Pinia 原生化。

## 3. 聚类设置与过滤规则

- 使用原生 TDrawer，1140px、52px 自定义标题、左侧蓝色关闭入口，保留遮罩关闭和源版本的 Escape 语义；接入既有弹层层级注册。
- 使用原生 TForm/TFormItem/TSelect/TInputNumber。标签在上，必填标记在右；字段长度保留 1–2000000 的整数限制；接口字段和完整提交数据未简化。
- 原库 `validate()` 的成功条件与 TDesign 不同，现仅 `result === true` 进入请求。校验失败、校验拒绝、请求失败或成功均释放保存 loading；请求成功才通知并关闭。
- 模板选择改为原生 TSelect，320px；保留搜索、模板管理底部入口、选择回调和编辑/解绑/刷新入口。已浏览器验证下拉、管理入口存在，Escape 只收起下拉。
- 过滤规则 Popup 使用受控状态，移除旧 showHandler/hideHandler。实测发现手动设置 visible 与 Popup 自身 click 切换重复，导致立刻收起；已让 Popup 作为单一切换来源。实际验证打开、取消、侧栏关闭及再次打开。
- 过滤规则外部点击识别 TDesign `.t-popup`；卸载解绑键盘和 document 监听。内部字段匹配、字段值缓存等源码逻辑保留。

**共享过滤规则内部仍有旧标签控件，RuleOperate 的切换确认/导入等也未全部替换，不计整个设置模块验收通过。** 本批没有保存已有业务配置，也没有解绑、重置、删除现有资源。
