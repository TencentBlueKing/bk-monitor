# 入口依赖收敛与条件采集

本次基于 upstream/feat/bklog-web-v3 的 2af0544efe，同步已合并的翻译依赖清理后继续优化。V1/V2、主应用交付目录和 Monitor 公开导出保持不变。

## 定位和实施

TDesign 旧兼容入口通过 namespace import 和 Object.values 遍历整个公开组件库，为其设置 MODE、COMPONENT_V_MODEL、RENDER_FUNCTION。遍历迫使打包器保留所有导出，未使用组件和图标进入启动依赖。

改为仅重写 TDesign ESM 模块对 Vue 的引用，在其调用 defineComponent 时通过专用 facade 应用原有 model/render 兼容元数据，保持同一 Vue 实例和组件对象身份。生产 Vite 与开发依赖预构建均应用同一转换；应用源码和其他 SDK 不经过该转换。移除原全库扫描入口，并更新迁移映射。

RUM SDK 此前在关闭采集时仍会静态加载。现在仅启用采集且配置 endpoint 时加载，初始化并发请求共享同一任务，失败可重试。bootstrap 在开启采集时等待 SDK 初始化，再发起原来的 preload 接口请求，用户信息关联顺序保持不变；SDK 加载失败时继续启动应用。Monitor 和关闭采集的场景不请求 SDK。接口过滤、URL 隐私处理及 SDK 参数保持原契约。

Vue 兼容运行时、IndexedDB 缓存恢复和当前翻译实现继续作为启动依赖；本次没有异步化缓存恢复、修改表单 refs/validate 时序或重写翻译行为。

## 构建统计

使用 analyze:bundle 对同一分支优化前后进行生产构建。数字为最终 JS 字节及独立文件 gzip 之和；统计静态 import 闭包并去重，不包含 CSS、接口耗时和额外交互。新增开启 RUM 的条件场景统计，不将该场景必载的 SDK 隐藏在指标之外。

- 入口静态依赖，关闭 RUM：3,323,848 → 2,630,607 字节（约下降 20.86%）；gzip 990,439 → 815,994（约下降 17.61%）。
- 入口开启 RUM，含初始化 SDK：2,805,060 字节；gzip 871,804。相比原入口仍有实际下降。
- 入口 + 检索路由：4,673,859 → 4,045,920；gzip 1,433,315 → 1,276,963。
- 入口 + 检索路由 + 趋势图：5,325,079 → 4,697,201；gzip 1,652,752 → 1,496,423。
- 上一场景同时开启 RUM：4,871,654 字节；gzip 1,552,233。
- 全部 JS：19,272,048 → 19,028,149；gzip 5,880,645 → 5,826,056。

这些数字不能直接换算为真实业务首屏时间。原始统计只保存在仓库外。
