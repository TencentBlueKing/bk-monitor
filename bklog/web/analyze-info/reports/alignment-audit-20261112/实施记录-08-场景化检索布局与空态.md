# 实施记录 08：场景化检索布局与空态

日期：2026-11-12。本批针对场景筛选区和结果空态做 V2 对照修复，不修改查询、操作符、字段依赖、远程选项或场景切换的业务流程。截图、DOM 尺寸记录、控制台及测试/构建日志仅存于仓库外的本地归档 `runs/implementation-20261112-08/`，不加入 Git。

## 原因与实现

源码依据为 V2 `views/retrieve-v3/search-bar/scene-filter/filter-panel.tsx`、同目录 SCSS，以及 `views/retrieve-v3/index.tsx/index.scss` 和原 Exception 图片/排版。V3 实现路径均相对 `packages/web-v3/src/`：

- `features/retrieval/workspace/search-bar/scene-filter/filter-panel.scss`：原固定布局为 32px 占位加绝对定位控件，但样式只识别 `.bk-select`，未识别 TDesign 实际根节点 `.t-select__wrap`。下拉框留在正常流中，额外撑高 32px，第一行前两项下移且第二行整体错位。本批增加原生根节点的定位选择器，保留原有占位、激活层级和 grid 规则；标签输入边框只作用于内部 `.t-input`，避免叠加双层边框。
- 同目录 `filter-panel.tsx`：恢复 V2 TagInput 未指定 placeholder 时的“请输入并按Enter结束”，显式配置的提示仍优先。没有改事件、值类型或选项加载。
- `features/retrieval/workspace/index.tsx`：未过滤和未匹配两种空态复用已有、基于 TDesign 的 EmptyStatus；使用项目内有来源/许可记录的 V2 search-empty SVG。关闭该通用组件的默认标题，只保留源页面自定义文案，避免额外出现“搜索结果为空”。原空态条件、加载条件、文字及联系入口全部保留。
- 同目录 `index.scss`：仅在 scene-empty-tip 作用域内去掉通用空态容器和内容的额外留白，并恢复标题、说明、详情的正常行高。未改变其他页面的 EmptyStatus 和全局 TDesign 样式。

## 验证与后续回归

本批以样式与展示修复为主，不新增镜像 CSS 的测试。使用既有全量测试、严格类型及主应用/APM/Trace 构建验证；全量测试 411 项、404 通过、原有 7 项失败；严格类型仍有 1566 条错误。主应用、APM、Trace 构建及资源检查均通过。完整日志、源摘要及最终结果仅存放本地 summary.json。

后续修改场景 grid、Select、TagInput 或空态时，必须：

1. 在两版同语言、同视口、同折叠状态下打开场景检索，先检查未过滤默认态。比较每项 label、控件和下一行的 y 坐标，不能只检查整体截图。
2. 检查有占位节点的绝对定位控件是否命中实际原生根节点；保持 32px 占位，不能简单删掉占位导致多标签撑开布局。
3. 验证主机/容器切换、下拉层打开/关闭、文本输入、已选多标签展开和清空。确认筛选值及操作符仍按 V2 代码处理。
4. 检查原图、默认文案是否重复、标题行高及上下边距；样式必须限定在场景空态，避免影响其他模块。
5. 再补 1440×900、1280×800、多标签溢出、筛选设置弹层、已过滤/未匹配及真实查询闭环证据。没有证据的分支保持待验证。
