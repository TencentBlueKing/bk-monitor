# 全模块主题覆盖收拢

> 后续更新：记录 29 已补齐原生控件内联样式扫描及迁移，并完成指定归档/ES 表单操作验证。聚类窄列经同视口 V2/V3 复核为两版共有行为。本记录以下统计和未验证事项保留为当批历史状态，最新结论以记录 29 为准。

## 完成范围

完成 V3 全模块 SCSS 和 Vue style 中的公共视觉值收拢、重复声明契约提取、源码归属台账及验证门禁。覆盖检索、采集、管理、归档、清洗、集群、提取、客户端、索引集、授权、脱敏、偏好共 13 个业务模块。

“覆盖收拢”不等于删除全部 `.t-*`：业务布局、组件内部状态适配、透明/继承值、代码区及其他特殊视觉仍保留在原上下文。本批没有把这些规则拼接成一份全局覆盖文件，也没有把静态覆盖率当作完整功能/视觉验收。

扫描范围是独立 SCSS 和 Vue style；TS/JS 动态 style、模板内联绑定及第三方包内部样式不由本台账证明覆盖。新增功能仍需遵循公共主题规范。

## 全量台账

`packages/web-v3/ai-native/theme-style-contracts.json` 记录 196 个包含 TDesign 类名或公共契约调用的样式文件，其中业务层 173 个：

- 清洗 5；客户端日志 5；集群 4。

公共层与应用壳也有明确归属；没有通过移除旧入口或缩小分母提高统计。每个文件登记组件类、公共契约、语义声明、上下文声明、特殊视觉属性及尚可规范化的声明数。

当前既定语义映射范围内，pendingNormalization 为 0。它只表示工具识别出的公共映射已处理，不表示所有硬编码视觉、所有选择器或所有局部覆盖清零。

## 落地内容

### 语义 Theme

在上一批 tokens.scss 基础上补充反色文字、较强正文、较大字号、校验强调/活动色、轻量焦点边框。现有颜色值不变；全部语义映射使用明确的原始值 fallback，保留当前默认外观。

本批共替换 343 处可共享的颜色、字号、行高、圆角与阴影声明。当前台账合计有 360 处语义声明（包含既有公共层声明），两者不是同一个统计口径。

转换只处理 TDesign 选择器上下文中的已知静态视觉值；不修改 width、height、padding、业务类、事件、接口或表单数据。不改动现有 var()/calc()/url()/动态 Sass 表达式，防止误改运行时样式。

### 重复组件契约

新增 `shared/styles/theme/components/contracts.scss`，提取 7 个具名公共契约：

- control-fill：内部控件填满容器。
- cell-editor：表格内嵌编辑器边框、圆角与边框过渡。
- join-next、join-previous：相邻拼接控件的单侧圆角。
- compact-control、compact-action：两种已存在的紧凑尺寸契约。
- filter-operator：采集与聚类共用的过滤操作符尺寸契约。

共替换 9 个文件中的 16 处重复声明。调用仍处于原业务选择器中，所以 Vue scoped、hover/focus 等状态及选择器优先级不变。没有将表格行高或过滤交互统一成原生默认实现。

### ConfigProvider

新增 `platform/ui/tdesign-config.ts`，集中持有已核对的组件默认配置，保持当前安装版本的行为。语言配置和显式业务 props 可以继续覆盖默认值。

`platform/i18n/locale-provider.ts` 按语言保存稳定配置引用：同一语言不重复生成配置，切换后仍复用该语言对象。避免父组件重渲染导致打开中的原生控件无意义重置。

主应用和 APM/Trace 使用同一 Provider 与主题入口；本批没有全局修改关闭确认、业务权限或表单校验逻辑。

## 编译等价验证

实际修改了 107 个样式文件（包括公共层）；107 个全部通过本地编译前后等价检查：

1. 旧源码仅保存在仓库外本地临时目录。
2. 以真实文件 URL 和原别名编译 SCSS/Vue style。
3. 将应用语义变量按当前主题的实际默认值解析，不仅比较 fallback。
4. 比较编译后选择器、属性值和 important；同规则的独立声明排序比较，因此不以此工具证明任意重复属性的顺序可交换。本批提取的契约没有重复属性。
5. 比较 Vue 文件 style 以外的全部内容，确认本批转换没有改动 template/script。
6. 对阴影中的 alpha 颜色使用 Sass 序列化，避免把等价的十六进制透明色与 rgba 误报为视觉变化。

这证明本批静态样式转换保留现有默认声明契约；不证明所有浏览器的最终计算样式、业务数据态或 V2 像素级一致。

## 统一命令及后续维护

新增 `pnpm --ignore-workspace check:theme`，已接入 verify：

- `tools/theme-style-coverage.mjs`：全量归属检查，未归档变更或尚可规范化的公共值使检查失败。
- `tools/check-tdesign-style-drift.mjs`：提示新增的业务 TDesign 类与 important 耦合。

辅助工具：

- `tools/tdesign-style-source.mjs`：保留字符串、注释、动态表达式和源位置的声明扫描及语义转换。
- `tools/normalize-tdesign-theme.mjs`：默认预览，写入模式必须提供仓库外本地源码归档。
- `tools/extract-tdesign-contracts.mjs`：只提取已审查的完全相同声明集合，不自动合并近似布局。
- `tools/verify-theme-style-equivalence.mjs`：针对仓库外旧源码执行编译等价检查。

新增/调整功能时：基础视觉优先使用语义 Token；重复控件外观复用公共契约或显式变体；局部布局继续由业务拥有。台账变化先审查再使用 `--write` 更新，不能自动把新增覆盖当成已接受。

门禁不检测所有 TS 动态样式和内联绑定，也不替代事件测试或浏览器验证。Theme 与嵌入宿主、同页第三方组件的彻底样式隔离仍需单独的兼容改造；本批保留既有挂载和作用域策略，避免顺带改变 Teleport 行为。
