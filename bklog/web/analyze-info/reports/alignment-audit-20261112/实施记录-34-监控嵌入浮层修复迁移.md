# 监控嵌入浮层修复迁移

来源：上游 PR #13280。问题是宿主侧栏高于日志字段配置浮层，导致入口看似无响应。

V3 使用已有公共层级方案实现等价修复：

- APM、Trace 的 initWindowState 在设置嵌入标志后初始化层级下限。
- 公共管理器复用 DIALOG 层作为监控浮层起点；默认分配和 nextTickIndex 均动态检查嵌入状态，兼容先导入模块、后初始化的顺序。
- 初始化幂等，不降低已有较高层级；接管旧宿主管理器时保留其计数。
- Registry 无全局管理器时也使用相同场景下限。
- 字段配置已由 BkLogPopover 经 Registry/Tippy 适配器动态分配层级；其内容样式改用公共 overlay 变量，移除 drawer 层语义。
- 无需迁移 Vue 2 prototype.$BK_EL 写入，也不在业务组件增加固定层级。V2 未改动。

验证：新增监控初始化、重复初始化、较高宿主计数、旧管理器适配、独立站及 Registry 兜底回归；层级相关测试全部通过。全量 474 项，468 通过，6 项既有基线失败。严格类型检查仍为 1562 项，仓库基准为 1271 项，回归命令不能视为通过。

APM、Trace 生产构建及产物校验均通过，各包含 52 个文件和 8 个公开导出；验证生成的产物不纳入本次源码修改。依赖图检查和主题覆盖检查通过。

未连接真实监控宿主执行端到端验收。复验时分别在 APM/Trace 宿主侧栏内打开字段配置，检查浮层可见、可选择、可关闭，嵌套浮层及消息高于父层，独立站正常。

记录仅包含实现与验证结论，不包含业务数据、截图或运行输出。
