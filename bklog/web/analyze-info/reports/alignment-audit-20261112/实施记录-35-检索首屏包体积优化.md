# 检索首屏包体积优化

## 范围和测量方法

仅优化 V3，V2、生产输出目录及公开 Monitor 导出保持不变。

通过 Rollup generateBundle 获取真实 chunk imports、dynamicImports、模块 renderedLength 与最终 JS 字节数，gzip 使用 Node zlib 默认参数。入口、检索路由、趋势图分别取其静态依赖闭包并去重；不把所有异步包都算作首屏。统计不包含 CSS、字体、接口耗时和浏览器交互时序，不能直接换算为首屏耗时。

分析脚本：在 packages/web-v3 运行 `pnpm --ignore-workspace analyze:bundle`。报告默认写入仓库外临时目录；可通过命令参数指定报告路径。只统计构建模块和大小，不读取业务数据。

## 实施

- AI 助手改为用户首次使用时加载，而非随检索路由静态加载。载入完成并等待组件挂载后再更新选项、执行原动作，保留首次动作参数及面板位置。失败可重试；页面销毁时注销自己的加载器，避免旧页面清理覆盖新页面。
- 趋势图改走 ECharts core，按需注册柱状、折线、坐标轴、标题、提示、滚动图例、工具栏、缩放、标记线/区间及 Canvas。其他图表仍可加载完整能力。
- 补充可复用的静态闭包分析工具和合成回归测试。
- 未保留没有 gzip 收益的翻译加载实验，现有翻译实现保持不变。

## 本地构建对比

单位为字节，各 gzip 数值为独立文件压缩量之和。

- 入口：3,323,469 → 3,323,848；gzip 990,351 → 990,439。基本不变。
- 入口 + 检索路由：7,028,062 → 4,673,859；gzip 2,188,958 → 1,433,315，下降约 34.52%。
- 入口 + 检索路由 + 趋势图：8,082,001 → 5,325,079；gzip 2,536,387 → 1,652,752，下降约 34.84%。
- 全部 JS：19,270,477 → 19,272,048。总体积基本不变，收益来自加载边界与首屏按需引入。

最终检索及趋势图闭包中未包含 AI SDK、Markdown 编辑器、Monaco 和 IP 选择器。Monaco、IP 选择器原本已是异步资源，本次没有移除其功能。

## 验证边界

新增回归覆盖 AI 延迟加载时保留首次动作及定位、加载失败重试、旧页面清理、真实 ECharts 注册后的堆叠柱状/折线/滚动图例/缩放还原，以及静态依赖闭包去重和排除延迟依赖。图表测试使用从零构造的数据和无绘制 Canvas，不代表浏览器视觉验收。

主应用生产构建、静态部署契约及产物校验通过。APM/Trace 生产构建与产物校验均通过，公开导出保持兼容；构建产物已排除出源码修改。严格类型检查仍为 1562 项既有诊断，没有新增数量。全量 478 项测试，472 通过、6 项既有失败，失败项仍需另行处理。

尚未进行真实宿主或真实业务页面的首屏网络、视觉及交互验收。原始构建统计和运行输出均留在仓库外。
