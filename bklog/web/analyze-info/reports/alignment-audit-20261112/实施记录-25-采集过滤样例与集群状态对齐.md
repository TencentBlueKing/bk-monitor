# 采集过滤、样例与集群状态对齐

## V2 依据与根因

对照 V2 新建采集配置页面、业务组件和已安装组件库样式。浏览器测得过滤组标题 32px、表头与规则行 42px、输入控件 41px；V2 Exception 的 part 场景图片为 100px。

1. V3 过滤表格沿用旧行高，但 TDesign Form 的 controls-content、Input 包裹层没有完整继承单元格高度；controls 固定高度又超过内容区，造成控件留白、边界不齐。Select 的默认边框也与 V2 嵌入式表格不同。
2. 日志样例将通用 Loading 挂在包含操作条的 form-box 上，显示固定上限的居中短骨架；它与下方编辑区尺寸没有对应关系。
3. 存储集群为空时，即使 loading 为 true 仍渲染空态，外层再叠加通用 Loading。空态组件位于 flex 容器中未占满宽度，出现靠左和大面积留白。

## 实施

### 过滤规则

- 保留 V2 的分组标题、表头、规则行及操作列比例。
- 局部补齐 TDesign 表单、controls、controls-content、输入包裹层的宽高和 min-width；清除该表格内空标签的布局占位。
- 输入内容区与 Select 对齐为 41px，保留 hover、focus 和校验错误边框；局部使用 border-box，避免边框撑宽分组。
- 未修改匹配/分隔符切换、过滤组逻辑、操作符、校验或提交协议。

### 日志样例

- 新增共享代码样例骨架：按编辑区全宽绘制三行内容，局部裁剪；不使用日志行号或固定居中宽度。
- 清洗步骤将 Loading 移至编辑区，工具条保持原位置，拉取期间保留不可点击反馈。
- 分隔符过滤中的日志样例也使用同一骨架，通过局部背景变量适配原有深色编辑区。
- 原样例拉取、刷新、调试和异步状态保持不变，没有增加等待动画的延时。

### 集群选择

- 移除整个集群区域的重复遮罩，由各组表格拥有加载反馈，加载时保留列头并按真实列宽绘制骨架。
- loading、空列表和有数据三个渲染分支互斥。加载中不出现“暂无共享/独享集群”，底层表格的默认空文案也不作为 Loading 背景显示。
- 使用项目统一空态组件，横向占满区域、居中展示；保持原 200px 区域，并采用 V2 的 100px part 图片。保留 24px 创建动作和原集群管理路由。
- 已有数据、单选、选中说明、创建入口和选择事件保留；没有改动集群接口、资源或采集下发逻辑。

## 验证

合成入口 `/__fixtures__/collection-create-ui` 挂载实际过滤和集群子组件，使用从零构造的输入，不初始化真实采集资源。工具区和样例加载由合成状态驱动；分隔符调试接口另由自动契约测试验证，不在浏览器场景中提交远程调试。

- V3 分组标题 32px、表头/规则行 42px、Select 和文本输入 41px，与 V2 测量一致。
- 清空必填值后原校验返回 false，错误边框仍显示且行高不变；新增过滤组后得到两个分组。
- 样例编辑区与骨架等宽等高，操作条不再被短横条跨区覆盖。
- 加载阶段无集群空态；结束后骨架移除，共享/独享空态各占满宽度并居中。
- 自动测试验证加载/空/结果分支互斥、选择事件和创建路由，回归原过滤控制与校验测试。

本批没有创建、编辑或删除真实采集/集群资源；没有把“下发成功”或全业务验收记作本次结果。V2 源码和依赖保持不变。
