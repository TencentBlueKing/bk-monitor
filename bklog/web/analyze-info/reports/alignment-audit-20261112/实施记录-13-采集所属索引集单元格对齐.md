# 实施记录 13：采集列表“所属索引集”单元格对齐

## 源码依据与根因

V2 的新采集列表使用自定义 TagMore 触发器，保留两行标签、省略提示、空态以及 hover/open 边框，仅通过标签内容框触发编辑。V3 原来仍向 bk-select 适配层传入 trigger 插槽，适配层没有转交该插槽，实际落成 TDesign 默认多选输入框：每行出现边框和箭头，已选标签带默认删除图标。

对照依据为 V2 `views/manage-v2/log-collection/components/list-main/table-list/table-list-v2.tsx` 与对应 SCSS；本次只修改 V3 的 `features/collection/current`，不修改 V2 应用。

## 实施内容

- 新采集表格的所属索引集选择器直接使用原生 TSelect，以 valueDisplay 渲染原有 renderTrigger/TagMore，不再依赖未支持的 trigger 插槽。
- 保留 TagMore 的两行标签、内容命中框、空态、hover/open 样式。隐藏原生输入框边框、下拉箭头和默认标签删除图标；触发区域高度保持源实现的 58px。
- 使用受控 popupVisible 与原有 editingIndexSetRowId 联动。标签内容点击开启编辑；无权限仍走原鉴权处理，只读分支不变，更新中不允许通过自定义触发器重新打开。
- 搜索框放在 popup 的 panelTopContent，使用 TSelect 原生 inputValue/filterable 执行筛选；没有新增后端协议或额外的业务搜索逻辑。
- options 仍来自原有 indexSetOptionList，选择只更新原有草稿。原 onToggle 的关闭后提交逻辑平移到 onPopupVisibleChange；新增索引集扩展区域移到 panelBottomContent，保留原组件、事件和提交逻辑。
