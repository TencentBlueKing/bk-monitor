# 管理侧栏与列表骨架

本批依据 V2 组件源码及实际页面，对齐 V3 管理模块。没有修改 V2，也没有提交业务配置。真实环境参数、截图、响应及运行日志不写入仓库；本记录仅保留工程结论和复验方法。

## Grok 侧栏根因与修复

源码依据：V2 `views/manage-v2/grok-manage/grok-slider.tsx/.scss`；V3 `features/grok/current/grok-slider.tsx/.scss`、`platform/compat/tdesign/legacy-bk-controls.tsx`。

存在三处独立的组件协议差异：

1. 旧表单的 `form-type="vertical"` 没有映射到 TDesign `labelAlign="top"`。原本用于纵向表单的标签宽度被当成横向标签列，挤占输入区。
2. `ext-cls` 没有映射到 Drawer 的 `drawerClassName`。仅传普通 class 也不能解决，因为当前 TDesign Drawer 不透传普通 class；由此导致 Grok、清洗模板等侧栏的局部样式未生效。
3. 旧 textarea 的 `rows` 不等于 TDesign Textarea 的行数 API。传到外层 DOM 上不会设置输入区域高度，需要映射为受限的 autosize；明确提供的 autosize 保持优先。

本批修正适配入口，并将 Grok 及归档侧栏的表单、内容和按钮样式选择器对齐到实际 TDesign DOM。纵向表单不再保留固定标签列；默认横向与 inline 表单保持原方向。表单数据、规则、验证成功/失败约定和输入事件不变。

兼容侧栏恢复默认关闭按钮及 Escape 关闭入口，支持异步 beforeClose 否决。Grok 将关闭确认结果返回给适配层：取消离开时不能继续发出关闭事件。未改变调试、提交条件或后端请求。

## 管理列表骨架

复用采集列表的 `app/skeleton/item-skeleton` 及动画，新增 `shared/ui/loading/management-list-loading.tsx/.scss`。其职责只限展示：

- 原表格始终挂载，保留真实表头、列定义、筛选、数据、分页、实例引用和事件；加载完成移除覆盖层。
- 读取当前表头的实际列宽及表体行高，按列逐行绘制占位；不读取或复制业务字段值。初始至少六行，已有结果时覆盖表体。
- 响应尺寸变化、水平滚动和表头列变化；监听及观察器在卸载时释放。
- 固定高度/最大高度表格仅绘制可见区域，不能通过最小占位高度撑大原滚动容器。普通表格为骨架预留表体空间，使分页位于骨架下方。
- 不并行叠加默认中心 Loading；支持减少动画偏好。请求状态、请求函数、权限、过滤或分页处理器不由骨架组件接管。

接入范围：Grok、ES 集群、归档仓库/策略/回溯及状态列表、日志提取配置/链路/任务、清洗列表、索引集列表、自定义上报、客户端日志上报/采集部署、数据链路配置，以及保留的相应兼容列表。清洗模板已复用采集的 TableComponent 骨架，本批保持其原实现。外部订阅 iframe 及其他应用拥有的列表不在本地加载状态改造范围。

上述是接入清单，不等于每条真实业务路由的完整验收清单。独立脱敏等未在本批接入和实测的页面，不能据此计为通过。
