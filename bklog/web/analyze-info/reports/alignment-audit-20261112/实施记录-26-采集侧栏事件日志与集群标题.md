# 采集侧栏、事件日志与集群标题

## 范围与依据

本批仅修改 V3。依据 V2 的 report-log-slider、step2-configuration、step4-storage 组件及其样式；使用 aafe-ui-design 的现有界面精修与视觉验收流程。浏览器只读打开两版新增采集页面，选择 Windows Event 后进入配置步骤，未提交采集配置。

## 原因与实施

1. 上报日志：旧侧栏内容和标题仍依赖旧组件结构，TDesign 抽屉未命中相关样式。替换为原生 Drawer 与 Button，保留 596px 宽度、完整 JSON 数据、五层展开、复制和关闭事件；正文采用原深色主题与内边距，标题操作为关闭按钮保留空间。无上报数据时显示空态并禁用复制，不拼造日志。数据源仍为原接口的 origin 字段，不以清洗样例替代原始上报日志。
2. 复制：旧工具函数在 document.body 中创建临时输入框，可能被抽屉焦点锁拦截。优先使用 Clipboard API，回退输入框放在抽屉内，完成或失败后清除；只有成功时提示成功，失败单独反馈。沿用复制完整 JSON 的语义。
3. Windows Event：旧样式只匹配旧复选框类，导致 TDesign 复选框横排。补齐本组件的原生选择器，恢复纵向排列及原尺寸、间距；自定义类别输入框使用显式业务类定位。选项、最后一个选项禁用保护、自定义值处理和提交逻辑保持原样。
4. 集群标题：移除仅包裹标题文字的灰底小块，标题占满折叠容器，保留图标、标题、说明层级，并允许长说明换行；折叠变更回写 activeName，保持内容及箭头状态一致。集群名称、数据选择和提交规则不变。
5. 新建按钮：两种采集列表视图统一使用 18px TDesign AddIcon；原权限、禁用条件和跳转事件保留。
