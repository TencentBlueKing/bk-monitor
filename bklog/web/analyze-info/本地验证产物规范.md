# 本地验证产物规范

截图、浏览器录屏、HAR、实际接口请求/响应、真实环境用例配置、运行日志和原始模型会话导出只保存在仓库外的本地目录，禁止加入 Git 或上传 GitHub。源码、合成测试夹具、行为契约、脱离真实响应的分析结论可以正常维护。

本地归档默认位于 Codex 的本地可视化工作区，具体位置由本地归档清单记录，不在仓库记录用户机器绝对路径。迁移验证工具仍使用 analyze-info/runs、scenarios 及原导出路径时，可建立被忽略的本地符号链接指向该目录；干净检出不会包含这些证据或链接。没有本地证据时应明确报告待验证，不生成伪造响应或通过结论。

当前本地归档保留文件校验清单以供核对。既有基准清单保留原摘要，不因证据移出 Git 而改为通过；相关工具在缺少本地文件时可能提示缺失，配置本地归档后再运行。

提交前执行 `git ls-files analyze-info/runs analyze-info/scenarios`，应为空。`git check-ignore` 应确认这些目录、原始 export 文件和验证图片已被忽略。`git status` 不应出现任何新截图、抓取数据或真实环境配置。

本次普通删除提交仅移除目标分支当前目录树中的文件，历史提交中的对象、其他分支、GitHub 缓存及派生仓库不会因此消失。历史清除需另行审计引用并协调历史重写；本次不执行强制推送。
