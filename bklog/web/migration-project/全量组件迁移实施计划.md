# 全量组件迁移实施计划

日期：2026-10-28。状态：计划已建立，按小模块逐项实施；不表示全量迁移完成。

## 1. 纠正执行方式

本次核心是稳定Vue2应用的Vue3升级。以完整源组件及其store/hooks/API/样式为迁移主体，保留业务分支；只改Vue3不兼容部分并做必要的类型和生命周期优化。浏览器对照用于辅助验证，禁止以简化页面或通用列表替代业务。

源运行时：`bklog/web/src`，Vue2.7。目标：`packages/web-v3`，Vue3。源码目录 `src/views/retrieve-v3` 是 V2 应用中的新版检索界面，不能因名字而排除。路由真实链：`src/router/retrieve.js → retrieve-hub.tsx → retrieve-v3/index.tsx`；toolbar 又引用 `retrieve-v2/sub-bar/index.vue`。旧 `retrieve/container` 是 retrieve_version=v1 分支，同样记录条件而非混用布局。

浏览器对照：8001/4173，同 spaceUid/bizId/indexId。40676 为本次必测索引，38131 为已有非空样本；40676 本次 V2 观测为检索无数据，必须验证空态，不能用另一索引的成功结果代替。

## 2. 每个小模块的工作协议

1. 源码分析：沿父入口、子组件、hooks/store、API、指令、SCSS 找全分支；记录 props/emit/slot、状态转换、权限、异常和副作用。
2. 建立契约：每个用户入口、可见控件及条件分支均分配场景 ID；记录源位置、预期、前置数据/角色、请求与状态，不能凭控件名字推断行为。
3. Vue3 重写：采用独立组件/composable，明确类型和单向状态；已支持Vue3的组件库直接保留原组件；@blueking/date-picker固定使用其Vue3入口，不再实现另一套日历。仅对不支持Vue3的基础控件使用TDesign适配，并保留原契约。不照搬演示 UI，不跨越目标目录修改 V2。
4. 对照：V2/V3 同窗口、同角色、同固定时间和数据；逐项验证默认、打开、选择、取消、禁用、加载、空、失败和权限状态。实时接口验证与固定数据视觉测试分别记录。
5. 验证：有意义的状态/事件测试、实际页面挂载、浏览器操作、局部/整页截图、相关模块回归、构建；保存命令、执行时间及源码快照标识。
6. 判定：业务通过、UI通过分开写。源码已写或测试通过不能自动变为已验收。缺环境/数据标阻塞，待验证不计入通过。只通过一个小模块不能外推整页。

每个模块产物：源引用清单、行为场景、实现文件、差异/截图、测试结果、剩余问题。不得擅自删减不理解的逻辑；新需求和产品调整单独登记。

## 3. 分批实施顺序及覆盖范围

### A0 全量盘点与初始化链

逐条对账下方具名路由，补嵌套容器、重定向、无名路由、动态组件和外链。对首次进入、空间恢复、索引默认值、URL恢复/分享参数、跨业务切换、权限、外部嵌入和父窗口通信建立场景。

先精读试点依赖，其余模块逐批展开完整组件树。静态列表仅为待分析入口，不能假称全仓业务已分析。建立共享依赖负责人，公共组件变动回归已验收模块。

### A1 全局布局与检索工具栏

按小模块顺序：自动刷新 → 历史查询 → 时间选择（全部预设、日历与绝对时间）→ 索引选择（分组、搜索、标签、快捷键、联合索引）→ 收藏开关与工具栏操作。同步恢复顶部空间/导航、外链、菜单、用户、帮助及相关权限。

每个弹层对照尺寸、位置、滚动、焦点、点击外部/关闭、禁用与选中反馈。不把原生 select 外观当作还原。

### A2 查询与场景检索

拆分 UI 条件编辑、操作符、值类型、嵌套逻辑、SQL/模式切换、编译/校验、AI 入口及事件；覆盖输入快捷键、条件增删/编辑、历史/收藏回填、IP chooser、URL同步。场景化检索独立分析场景选择、筛选、表条件、无场景与历史协议，不能复用普通检索参数冒充完成。

### A3 字段区与检索结果

字段树、内置字段、搜索、统计/气泡、别名、显示配置/顺序/持久化、拖拽、折叠宽度；趋势的时间缩放、周期、收起、刻度、错误与仪表盘/策略入口；原始/表格、排序、分页/加载更多、行号、换行、高亮/划词、JSON、字段值菜单、上下文日志、详情侧栏、下载与导出历史、实时日志、模板管理。分别覆盖数据类型、无数据、大文本、错误、权限、取消与竞态。

### A4 收藏与聚类

收藏分组/检索/新增/编辑/删除/拖动/恢复及共享；聚类未接入/不支持/已接入分支、接入向导、算法/级别、结果分页/排序、Pattern详情与标注/屏蔽/对比、策略、趋势和导出。严格跟随开关和权限，读流程与配置写入分开验证。

### A5 检索相关独立入口

APM/Trace、客户端日志、分享/过期/授权、data_id跳转、授权列表、模板管理。覆盖独立路由和嵌入式差异，不以复用检索组件为由跳过验证。

### B1 采集与索引集完整流程

采集列表/筛选/分页/操作、新增/编辑向导、主机/容器/标签/应用类型、路径/过滤/联动校验、字段清洗、存储、脱敏、启停/重试/状态详情；计算平台/ES/自定义上报/SDK接入、索引集创建/编辑/详情/权限。先验证一种完整新增/编辑，再补所有场景分支。

### B2 数据管理

清洗与清洗模板、Grok、脱敏规则，提取任务/创建/克隆/链路、归档仓库/策略/回溯、ES集群、订阅、采集接入追踪、链路配置与设置。每条路由单独核对源页面、表单、校验、权限、接口、状态回显和异常恢复，不使用 ResourcePage 的通用列替代。

### B3 仪表盘及导航

还原旧导航打开监控/仪表盘的外链语义，同时对账旧站内仪表盘首页/默认/创建/目录/导入路由实际可用范围。不能用目录接口表格替代图表或编辑器。

### C 全量验收与经验固化

全路由及角色矩阵、关键读写闭环、默认/交互/异常/弹层视觉、浏览器和嵌入兼容、构建/部署/回滚。所有差异解决或有明确批准；规则/契约/失败记录从已验证流程抽取，最后写经验总结。
