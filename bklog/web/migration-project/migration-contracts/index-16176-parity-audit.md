## 已确认并修复

1. **更多菜单为空**：Pinia 状态可能在菜单挂载前已恢复，原 watcher 没有执行初始化；增加 immediate，并从 getters 正确读取联合查询状态。正常索引已恢复“采集详情”，联合状态另有组件逻辑测试。
2. **官方时间面板打不开**：只给 DatePicker 根组件设置 MODE 3，无法覆盖 BKUI 私有的 PopReference 等组件。限定官方 Vue3 SDK 模块的 Vue 导入，在组件定义时设置原生模式；开发预打包与生产构建使用同一规则，保留单一 Vue 运行时。没有改写时间组件、修改压缩产物或全局切换兼容模式。真实页面预设、日期和时区入口恢复。
3. **表格表头操作失效**：Vue3 h() 仍接收 Vue2 `on/directives` 参数。修复排序与移除字段事件，提示改用 TDesign Tooltip。浏览器中 V2、V3 点击 level 后都出现升序状态；测试覆盖升序、降序、清除及移除字段的原有调用顺序。真实用户字段配置未执行删除。
4. **图表分析无响应/崩溃**：Monaco 实例放在深 ref 中，被 Vue3 代理后破坏命令式实例身份。改为 shallowRef，保留实例本身；新增循环对象图和私有成员测试。V3 已重新显示 SQL 聚合结果 minute1 / log_count，页面保持可交互。
5. **字段值/划词菜单缺失标识与事件**：同类源码扫描进一步发现菜单仍使用 Vue2 attrs/on。V2 有 owner 和 item 标识，V3 原先均无，影响实例定位和菜单操作。改为原生 DOM 属性、事件、图片地址及 TDesign 提示。浏览器中的操作项已恢复，实际“高亮”产生 12 个命中标记。测试覆盖回调参数、多个实例 owner 隔离及 Trace 入口限制。
