## 依赖不能混装

根目录继续用 npm 和 `package-lock.json`。pnpm workspace 只有 `packages/web-v3`，见 `pnpm-workspace.yaml`。

不要在 `bklog/web` 执行 `pnpm install`。那会把根 `node_modules` 换成 pnpm 布局，`vue-loader@15` 会连到 Vue 3 的 `@vue/compiler-sfc`，旧版 webpack 编译失败。若根依赖已经被打乱，在 `bklog/web` 执行 `rm -f pnpm-lock.yaml && npm ci`，不要用别名把 `@blueking/bkui-library` 指回 Vue 2。

只安装 Vue 3 包：

```text
pnpm --dir packages/web-v3 --ignore-workspace install
```

Node 使用 `.nvmrc` 的 `26.12.1`。交互 shell 若仍是别的版本，先 `nvm use`。

## 怎么对照运行

命令都在 `bklog/web`。

| 应用 | 命令 | 本轮对照地址 |
| --- | --- | --- |
| Vue 2 | `npm run dev` | `http://appdev.woa.com:8001/#/retrieve/38131?spaceUid=bkcc__5000140&bizId=5000140` |
| Vue 3 | `pnpm --dir packages/web-v3 --ignore-workspace dev` | `http://appdev.woa.com:4173/#/retrieve/38131?spaceUid=bkcc__5000140&bizId=5000140` |

Vue 2 开发服务默认端口是 8001。`AAFE_E2E_PORT=8011 npm run dev:e2e` 是另一条 e2e 启动方式，不要和 8001 的日常服务混用。

两边都通过 `local.settings.js` 把 `/api` 代理到同一套后端，并带上其中的请求头。Vue 3 的 Vite 配置必须先切到 `bklog/web` 再加载这份配置，否则读不到 `./.cookie`。不要把 Cookie、CSRF 或 token 写进文档、日志或提交。

Vue 3 使用 hash 路由，所以检索地址形态与 Vue 2 相同：`/#/retrieve/:indexId`。`server.allowedHosts` 需要包含 `appdev.woa.com`，否则该域名会 403。

旧版 webpack 若报 `@blueking/bkui-library` 缺少 `h` 或 `reactive`，先确认没有残留进程还拿着已删除的 pnpm 依赖图，再清 `bklog/web/.cache` 并用 Node 26.12.1 重启 `npm run dev`。

## 路由

`migration-project/migration-engine/extract-routes.mjs` 从 Vue 2 路由文件抽出具名路由，写到 `packages/web-v3/src/router/legacy-routes.json`。抽取时每条 `path` 只能切到下一条 `path`，否则名字会串到别的对象上。

已抽出 87 条具名路由。Vue 3 用 hash history 挂上它们：

- `manage`、`log-collection`、`collection-item` 重定向到采集项列表。
- `dashboard` 重定向到首页。
- 检索类路由使用 `RetrievePage`。
- 无权限类使用 `ExceptionPage`。
- 其余资源路由使用 `ResourcePage`，按 `src/features/query.mjs` 的 `resolveFeature` 调用 Vue 2 已有列表接口。
- 额外增加了站内 `/monitor`。Vue 2 顶栏「监控策略」打开的是 `MONITOR_URL` 新窗口，「仪表盘」顶栏打开的是 Grafana 地址。这个站内页是替代，不是旧版路由。

`resolveFeature` 的匹配顺序要保持：`manage-collection` 必须单独归到采集列表；`bk-data-collection` 不能被更宽的 `collection` 规则抢走。

## 检索页

对照页是索引集 `38131`，空间 `bkcc__5000140`。空间名来自 `GET /api/v1/meta/spaces/mine/` 的 `space_name`，顶栏短标是首字母大写。这个空间显示为 `D` 加 `demo`。业务列表 `GET /api/v1/bizs/` 不是顶栏文案来源。

索引集下拉的文案按 Vue 2 `buildLightenName`：名称后面接结果表 ID，最多 3 个，更多则 `+N`，没有结果表时后缀是 ` ()`。

查询体与 Vue 2 `getDefaultRetrieveParams` 对齐，实现在 `packages/web-v3/src/features/query.mjs` 的 `buildRetrieveQuery`：

- `POST /api/v1/search/index_set/:id/search/`
- `keyword` 空值写成 `*`
- `search_mode` 为 `ui`
- `interval` 为 `auto`
- 时区 `Asia/Shanghai`
- 时间是 unix 秒。默认预设 `now-15m`
- `addition` 为 `{ field, operator, value: string[] }`
- 未点「日志排序」时 `sort_list` 为 `[]`。点排序后按字段接口的 `default_sort_list` 在 `asc`、`desc`、取消之间切换

字段来自 `GET /search/index_set/:id/fields/?bk_biz_id=`。该索引集 `display_fields` 为 `dtEventTimeStamp`、`serverIp`、`log`。可选字段按点号收成树，`__ext.*` 收成一组；`src/const/index.js` 的内置隐藏名单默认收在「内置字段」里。这和 Vue 2 字段栏的分组来源一致，还没有字段拖拽、统计气泡和别名。

趋势图请求 `POST /search/index_set/:id/aggs/date_histogram/`。请求里的 `interval: auto` 会得到 0 个桶，因此按时间跨度改成 `1m`、`5m`、`30m` 或 `1h`。页面上仍写「汇聚周期 : auto」，与 Vue 2 展示文案一致。

日志聚类先看字段接口 `config` 里的 `clustering_config.is_active`，不先打 pattern 搜索。这个索引集该开关为 false，且存在 `text` 字段，所以展示 Vue 2 `QuickOpenCluster` 的说明，不展示「聚类配置不存在」。接入向导会调用 `POST /clustering_config/:id/access/create/` 并改真实配置，尚未迁移，页面上也没有做成无请求的空按钮。没有 `text` 字段时走 Vue 2 的空聚类文案。开关打开后才应请求 `POST /pattern/:id/search/`，请求体默认值来自 Vue 2 `requestData`（`pattern_level` 为 `05` 等）。

2026-10-27 在 Vue 3 页面上核对过的行为：

- 字段栏为显示字段三项、可选字段 `__ext (10)` / `bk_host_id` / `cloudId` / `path`、内置字段收起。
- 近 15 分钟空关键字结果为 157 条。同一时刻 Vue 2 曾是 156 条，差值来自时间窗口滑动，不是另一套查询体。
- 「日志排序」一次后，`sort_list` 为 `dtEventTimeStamp`、`gseIndex`、`iterationIndex` 的 `asc`，首行时间从窗口末端移到窗口起点。
- 「原始 / 表格」会切换列。展开行能看到该行字段名。点击 IP 会按该字段的 `field_operator` 追加 `addition` 再查询。
- 「日志聚类」显示「快速开启日志聚类」，没有 pattern 接口错误。

这些核对只覆盖检索页的上述交互。不能据此写成像素级一致或功能迁移完成。

## 还没有对齐的检索能力

以下在 Vue 2 检索页上存在，Vue 3 尚未按源码接上：

- 左侧收藏，以及收藏宽度和选中态。
- 场景化检索。当前「场景化检索」按钮没有切换数据。
- 历史查询。
- Vue 2 检索输入框本身：UI / SQL、条件编译、AI 模式。Vue 3 只有关键字框，以及点「添加条件」后出现的字段、操作符、值。操作符必须来自字段的 `field_operator`，不能写死 `contains`。`log` 这类 `text` 字段的「包含」是 `contains match phrase`。
- 日志 JSON 格式化、划词高亮、级别色条。当前只对级别词和数字做了着色。
- 行展开侧栏、字段拖拽、字段设置、高亮、下载、实时日志。
- 趋势图的纵轴刻度、添加到仪表盘、添加告警策略。
- 顶栏用户、分享、索引配置、告警、全局设置，以及「回到旧版」。
- 聚类接入向导、聚类结果表、Pattern 操作。

时间预设目前只有 5 分钟、15 分钟、30 分钟、1 小时、6 小时、24 小时、7 天。Vue 2 快捷项里还有 3 小时、12 小时、2 天等，没有照搬全量列表。

## 其他页面
