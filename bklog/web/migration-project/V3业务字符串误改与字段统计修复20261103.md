# V3 业务字符串误改与字段统计修复（2026-11-03）

本批发现并修复了源码搬迁时业务字符串被改写的问题，同时继续恢复字段统计交互。全部改动以 V2 实际源码为依据；当前仍处于实施和验收中，不构成全业务通过声明。

## 业务字符串误改

历史 `migration-engine/organize-vue3-source.py` 对全部引号字符串执行路径解析和重写，未区分模块引用与业务数据。源码中的 `.`、`../` 若恰好解析到包含 index 的源目录，就会被改为 `./index`、`../index`。该脚本是已归档的一次性重组工具，不应在当前源码上重新运行。

本批逐处核对 V2 后，在 12 个文件恢复 21 处业务字面量：

- `shared/global/head-navi/index.tsx`：域名拆分和拼接。
- `shared/global/json-view/index.ts`：JSON 对象字段路径拼接和 DOM 字段路径绑定。
- `features/collection/access/step-field.vue`：对象子字段识别、一级字段拆分和内置字段匹配。
- `features/charts/value-formats-package/value-formats.ts`：小数点位置和精度计算。
- `features/retrieval/workbench/field-filter-comp/field-item.tsx`：对象子字段短名称。
- `features/retrieval/workbench/components/text-segmentation/index.tsx`：嵌套字段路径解析。
- `features/retrieval/workbench/search-result-panel/graph-analysis/sql-editor/lang.ts`：Doris 嵌套字段识别及 SQL 片段生成。
- `features/retrieval/workspace/search-result/original-log/components/origin-log-result/index.tsx`：原始日志嵌套属性读取。
- `features/extraction/current/extract-config/config-slider.tsx`、`features/extraction/classic/manage-extract-permission/directory-manage.vue`：目录名称不能以点开头的原校验。
- `features/extraction/download/create/preview-files.vue`、`features/extraction/current/extract-task/task-create/preview-files.tsx`：返回上级目录的原 `../` 参数。

上述错误会使界面仍可显示却无法正确取值、定位或回填，不能用构建成功替代业务验收。未对业务规则作推测补充，也没有改写合法模块导入。

新增 `tests/business-literal-parity.test.mjs`：13 项测试，逐文件解析 V2/V3 源码比较业务字面量，并扫描 V3 防止目录解析标记再次进入分隔符调用。新增导入重写器应只处理 AST 中的引用节点；不应继续对所有引号内容作路径替换。

## 字段统计交互

源码依据：V2 `views/retrieve-v2/field-filter-comp/{field-item.tsx,field-analysis.tsx,agg-chart.tsx}`。V3 对应 `features/retrieval/workbench/field-filter-comp`。

- 字段统计入口原本调用不存在的 `$bkPopover`，导致统计逻辑执行但无可见弹层。改为受控原生 TDesign Popup，保留可统计类型、es_doc_values、联合冲突及前端统计分支的原判断。
- 标题与图标继续使用原显式打开处理；修复标题打开事件被随后外部点击判断立即关闭的问题。Popup 更新改为原生实例方法，关闭/卸载后可安全处理延迟定位回调。
- 字段类型、冲突、操作及统计值提示迁为原生 Tooltip/Popup；错误和空态迁为原生 Empty，保留原提示及异常原因。
- 全量去重详情迁为 480px 原生 Drawer，同域 body 托管；保留无遮罩、左侧关闭、下载和对象值统计。补齐 V2 的外部点击关闭行为，组件卸载清理文档监听，并依据 composedPath 保留内部点击的原始归属。
- 聚合值搜索框使用原生 Input，保留搜索、清空、右侧图标；提示继续安全处理原转义文本，添加/排除条件保留原请求语义。
- 保留前端统计、普通、联合、场景和嵌入请求参数，聚合键仍使用 field_name，不能将显示别名写进请求。
- 字段统计旧类组件的翻译能力按现有 ApplicationInjections 的 `$t` 契约作接口声明，不生成运行时字段、不引入旧 UI 全局服务。现有 Babel 不支持在该装饰器链中声明 declare 字段，已改用接口合并。

新增 `tests/field-analysis-native.test.mjs`，覆盖字段短名、请求上下文、原生打开/关闭、延迟定位、字段显隐事件、统计排序/搜索、原生 Input 渲染、旧控件禁用和侧栏监听清理。本批全套 304 项测试通过，严格类型诊断 1924 条；主应用、APM、Trace 构建均通过，快照标识见 result.json。

## 条件与字段树修复

聚合值添加/排除条件原为类实例箭头函数，捕获了装饰器采集数据时的临时 this，无法访问实际组件的路由实例。改为原型方法，保留 V2 的条件构造、store 提交和事件顺序。真实浏览器验证 iterationIndex = 0 更新 URL 并得到 390 条结果；!= 0 得到 2308 条结果。计数为动态样本，不能替代固定数据一致性验证。

左侧字段树改为原生 TDesign Tree，保留完整字段元数据、短名、层级、搜索展开和懒加载；移除不存在的实例 filter 调用。修复原迁移误改的点号分隔符后，labels.app 可匹配三个叶节点。原生树行支持长名称换行，关闭后的节点不占空白高度。已验证 __ext、labels 两层展开及收起。

字段拖拽改用 Vue3 Draggable 4 的 item 插槽，保留字符串顺序模型与 fields-updated 事件。厂商类型遗漏真实支持的 end 事件，增加局部精确类型声明；未创建包装组件或放宽全局类型。为保护已有个人字段配置，未对现有索引实际拖拽持久化。

新增 field-tree-native.test.mjs 4 项；field-analysis-native.test.mjs 13 项，包括实际宿主 this 的路由回填回归测试。
