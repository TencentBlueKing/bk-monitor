## 额外发现的触发区兼容问题

TDesign Select 的可搜索输入会替换自定义 trigger，无法完整保留 V2 的“有样例仍可手动修改列号”。改用共享的 `features/collection/shared/sample-column-select.tsx`，使用原生 Popup/Input、语义化选项列表，并保留 ArrowUp/ArrowDown/Enter/Escape 与独立搜索草稿；两个业务组件各自提供原来的输入触发区，不合并校验逻辑。

空数字输入通过键盘获得焦点时必须同步进入编辑态，否则首个字符会触发展示态切换、卸载 InputNumber，随后被其失焦清空回调覆盖。显式焦点处理和字符串数字模式解决此问题，新增实际处理器回归测试。真实页面已验证：选择样例第二列后可以手动改为第四列；从空值输入第五列后，失焦显示“第5行”，调试样例与搜索 omega 不会覆盖列号。

TDesign API 依据：[Select](https://tdesign.tencent.com/vue-next/components/select?tab=api)、[Form](https://tdesign.tencent.com/vue-next/components/form?tab=api)，并核对当前锁定版本的本地类型与实现；未依赖未公开的 valueDisplayOptions。
