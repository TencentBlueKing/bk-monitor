## 本轮纠正的误报和验证边界

1. 固定不动的 Date.now() 导致 Vue 原生事件时间戳防护拒绝 SVG 冒泡，曾表现为图标按钮不生效。该产品缺陷判断撤回。增加固定时钟负例和恢复推进后的正例；初始化请求日期固定，完成后恢复推进再做无请求的局部交互。其他时间敏感场景需单独设计。
2. 截图早于 V2 的透明加载遮罩退出，会造成真实空态被命中测试判为遮挡。现在等待实际遮罩隐藏和有限动画稳定，没有放宽遮挡比较。
3. 原生 TInput 会在根 click 中重新聚焦。展开区搜索按钮停止向根冒泡；清空在根回调后通过公开 blur 方法恢复 V2 焦点。一次 nextTick blur 方案因早于根回调而失败，已移除。
4. V2 的空态“清空筛选条件”会重请求；返回空列表时提前返回，可能保留搜索空态提示。本地清空图标不是该操作。该分支单独保留待验证，不伪造为恢复默认空态。
5. 检索新录制绑定场景、操作脚本、断言、策略及工具摘要；变更后拒绝复用。管理场景的同等绑定、V3全量源码/样式产物在运行前后固定仍待完善。
