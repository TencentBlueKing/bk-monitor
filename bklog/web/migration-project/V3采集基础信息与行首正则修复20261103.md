## 源码依据与实现

以 `packages/web-v2/src/views/manage-v2/log-collection/components/business-comp/step2/` 下的 `base-info.tsx`、`line-rule-config.tsx` 和 `multiline-reg-dialog.tsx` 为依据，在 V3 同职责目录直接使用 TDesign。

基础信息保留采集名、数据分类、数据名、所属索引集、备注、格式校验、5～50 字符、后端重复检查、编辑态禁用和自动转换。Input 使用值回调；备注恢复 Textarea。Form 校验失败时继续向步骤协调器返回拒绝 Promise，避免原生错误对象被当作成功。

行首正则保留完整 collection params、最多匹配行数、超时和原有非空校验。调试弹窗保留旧正则回填、输入 trim、匹配请求及结果、保存回填和关闭清理；原生 Form 校验失败不调用接口。使用实际已存在的富文本翻译组件保留匹配数量样式。关闭重开使旧响应失效，提交数据使用当次快照，避免清空弹窗草稿影响请求。
