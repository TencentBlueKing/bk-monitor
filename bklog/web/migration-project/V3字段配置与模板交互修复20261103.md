## 复现并修复的运行时故障

1. 打开字段面板报 `window.__bk_zIndex_manager.nextZIndex` 不存在。共享 PopInstanceUtil 及 ES 信息侧栏改用项目统一 overlayRegistry，宿主存在层级管理器时仍复用宿主；缺失时使用注册表递增层级。
2. 点击左侧字段设置报 `$bkPopover is not a function`。改造外层菜单与模板列表，删除该调用链的旧全局依赖。
3. 点击移除已选字段时，Vue 更新移除目标 DOM，随后 document 点击监听无法再由 target.closest 找到弹层，误关闭面板。共享点击判断补用原始 composedPath；真实页面复测可连续移除，面板保持打开。
