一个小模块必须交付：源码依据和行为契约、实际修改文件、测试/请求效果、对照截图、剩余差异及明确状态。共享改动先做影响分析，回归已通过消费方。连续两轮失败回到根因分析，保留失败和修复记录。

禁止使用 `migration-engine/organize-vue3-source.py --apply`。历史工具曾把普通业务字符串 `.`、`../` 当作模块路径改坏；修复名单和回归见 `V3业务字符串误改与字段统计修复20261103.md`。未来路径变换只允许识别真实AST import/export/import()/require或明确样式引用。

兼容全局MODE2仍有业务依赖。不得提前全局切MODE3；仅在原生组件/SDK岛使用相应局部模式。不要为类型检查重新声明未安装的$bkPopover/$bkInfo等服务。TDesign Form失败可能正常返回错误对象，必须检查返回值是否严格等于true。

TDesign Select不能直接替代所有V2自定义触发区，Table列插槽、Form校验、Dialog自动关闭、Popup挂载、Checkbox受控值、draggable item slot 都要逐项核对。不能用“组件名称已改”为验收标准。
