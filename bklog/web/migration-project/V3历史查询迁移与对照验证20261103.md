本批以 V2 的 16176 业务为参考，完成历史查询面板的原生 TDesign 改造，实际验证普通检索中的 UI/SQL 回填。联合、场景模式完成源码契约对照，尚未完成真实浏览器闭环，整个模块及全业务不标记为通过。

## 源码和行为依据

- V2 实际组件：`packages/web-v2/src/views/retrieve-v2/sub-bar/query-history.vue`；不能因为上层入口名字包含 retrieve-v3 就视为 Vue3 组件。

原组件通过旧 `$bkPopover` 移动隐藏 DOM，同时重复使用 historyUlRef；它包含搜索、模式图标、条件提示、收藏入口，以及三类不同的历史接口。不能用单一字符串列表或普通查询接口替代这些分支。

## 实现内容

1. 使用 TDesign Popup/Input/Tooltip 和现有原生 Loading 组件，删除该业务组件的旧弹层命令、旧 Input 和指令依赖。Vue 继续持有完整组件树，不再手动移动节点。
2. 历史状态、请求及回填提取为类型化 useQueryHistory。保留既有 ServicesInstance 调用和后端协议：普通使用 index_set_id，联合使用 index_set_ids，场景使用 space_uid/table_id_conditions/scene_filter_values。
3. 保留过滤裸通配符 `*`、ConditionOperator 转换、关键词过滤，以及 keyword/addition/ip_chooser/search_mode/scene_filter_values/table_id_conditions 的完整回填。没有重写条件编译或扩充业务规则。
4. 保留搜索内容在关闭后重新打开时的状态。清空关键词可恢复列表；筛选无匹配时保留 V2 原有空列表行为，没有擅自增加新的业务分支。
5. 使用原 BookmarkPop，保留 Monitor 排除分支。收藏按钮定位到行右侧，点击不冒泡为历史回填；子弹层打开时阻止父弹层提前关闭，取消后父面板保留。
6. 增加请求代次保护：关闭、切换查询上下文或卸载后不接收旧响应；重新打开时旧请求不能结束新请求的加载状态。强制重置同时释放收藏子弹层关闭保护。
7. 提示内容使用 Vue 文本插槽，继续显示检索时间和原查询语句，避免依赖手工 HTML 拼接。
