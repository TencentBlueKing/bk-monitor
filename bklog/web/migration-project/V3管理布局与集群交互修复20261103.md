V3 实现：

1. `src/features/management/manage/index.vue` 使用明确的侧栏和主内容 flex 容器；原生 TDesign Menu 仅承载菜单，router-view 不再作为菜单项渲染。保留权限、分组、功能开关、旧链接和导航操作。普通左键走原路由处理，修饰键点击保留链接默认行为。
2. `src/features/clusters/current/cluster-manage/es-slider.tsx` 使用原生 Drawer 的 visible/default/header/close 协议。所有关闭入口先等待原 useSidebarDiff 判定，异步确认期间抑制重复关闭。弹层层级交由既有 overlayRegistry 管理。
3. 同一文件使用 Form.data、FormItem.name、requiredMark；连通性测试和 ES 提交仅在 validate 返回 true 时继续。保留原请求字段、编辑 ID、密码掩码清除、冷热节点获取和默认分片数设置。Doris 独立提交分支保持原代码。
4. 基础连接信息的 Input、InputNumber、Select、Option 使用原生 TDesign 控件和 value/label 协议；来源和协议下拉层级高于抽屉。
5. `src/features/clusters/current/cluster-manage/index.tsx` 使用原生 Table.columns，逐列保留原渲染逻辑、显示条件、权限、禁用条件及操作。ID 和连接状态使用不同列标识，避免冲突。
6. 原分页状态显式转换为 current/pageSize/total/pageSizeOptions；来源和连接状态筛选值转换后交给原过滤流程。false 状态使用字符串 false，不能被当成清空。清空筛选同步清理两层筛选状态。
7. 列设置使用原生 Popup、Checkbox 和 Button：打开复制草稿，全选保留固定字段，确认使用原字段持久化函数，取消不修改已选字段。创建时间排序使用当前页数据比较，保持原前端分页行为。
