# DDD Project Discovery

## Activation

Only execute when DDD Gate = ENABLED.

## Purpose

Understand the existing project before DDD modeling.

## Analyze

- project structure
- language
- framework
- modules
- packages
- APIs
- persistence
- existing architecture
- business entry points
- business workflows
- tests
- existing domain abstractions

## Do Not

- redesign architecture
- create aggregates
- create bounded contexts
- modify code

## Output

- ProjectModel
- ArchitectureModel
- BusinessCandidateModel
- DDDReadinessModel

## Schema

`.ai-agent/ddd/schemas/project.schema.json`
