# DDD Code Mapping

## Purpose

Map the DDD model to the existing implementation.

## Mapping

```text
Domain Concept -> Existing Code -> Current Responsibility -> DDD Gap -> Target Responsibility
```

## Output

- DomainToCodeMapping
- CodeToDomainMapping
- ResponsibilityViolations
- ArchitectureViolations
- RefactoringCandidates

## Schema

`.ai-agent/ddd/schemas/code-mapping.schema.json`
