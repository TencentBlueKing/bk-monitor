# BKLOG Web 技能索引

本文件是 BKLOG Web 前端项目的技能索引，按需加载对应域的技能。

## 项目技能

| 技能域 | 路径 | 说明 |
| --- | --- | --- |
| frontend-developers | `./project-skills/frontend-developers/SKILL.md` | 前端开发者列表与 TAPD 任务分配排查 |
| log-search-overlay | `./project-skills/log-search-overlay/SKILL.md` | 日志检索弹出统一管理（Overlay Registry） |

## 加载策略

- 当任务涉及前端开发、前端任务分配、TAPD 前端需求排查时，加载 `frontend-developers` 技能。
- 当任务涉及检索页 popover / tippy / Dialog / 浮层生命周期 / 关后再打不开 / 飞到左上角时，加载 `log-search-overlay` 技能，再按 SKILL.md 选型与八条契约改代码。
- 技能加载后，按 SKILL.md 中的规则执行。
