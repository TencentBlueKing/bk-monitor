# Structural Patterns

覆盖 14 个模式：

- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy
- Wrapper
- Module
- Layer
- Anti-Corruption Layer
- Data Mapper
- DTO
- View Model

## Rules

STRUCTURAL-001
Adapter MUST translate incompatible interfaces.

STRUCTURAL-002
Facade MUST simplify a complex subsystem.

STRUCTURAL-003
Facade MUST NOT become a God Object.

STRUCTURAL-004
Decorator SHOULD preserve the wrapped component contract.

STRUCTURAL-005
Proxy MUST have an explicit interception purpose.

STRUCTURAL-006
Composite MUST represent meaningful tree structures.

STRUCTURAL-007
Flyweight SHOULD only be introduced when object duplication creates measurable cost.

STRUCTURAL-008
DTO MUST NOT automatically become a Domain Model.
