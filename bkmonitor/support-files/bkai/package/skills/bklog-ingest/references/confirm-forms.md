# 确认表单页

配置补齐后，必须用本节的**表单页**给用户确认。不要再用纯文本清单。

三种已沉淀接入类型各有一页：主机、容器日志、容器标准输出。Windows Event 未沉淀，不要套这三页。

表单页分两块：

1. **配置表单**：两列表（配置项 / 内容），缺的行不要编造。
2. **对象表**：主机用「采集目标」表；容器日志、容器标准输出用「采集配置范围」**竖表**（配置项 / 内容，一条 `configs` 一张，禁止横表）。

底部固定两个操作，用户必须选其一后才能写接口。选定后立刻下发，不要等清洗配完：

- 直接下发
- 下发并清洗

用户改任何一行，更新表单后再确认。

聊天里就按下面的 Markdown 表格输出，不要改成段落。

## 1. 主机采集 · 确认采集配置

```markdown
## 确认采集配置

| 配置项 | 内容 |
| --- | --- |
| 接入类型 | 主机采集 |
| 采集名称 | |
| 数据名 | |
| 日志类型 | 行日志 |
| 字符集 | UTF-8 |
| 采集范围 | 仅采集下发后的日志 |
| 上报链路 | 不可调整 |
| 存储集群 | |
| 过期时间 | 3 天 |
| 副本 | 0 |
| 分片 | 3 |

### 采集目标

| 目标类型 | 云区域 | 对象 |
| --- | --- | --- |
| 静态拓扑 / 动态拓扑 / 动态分组 | | |

### 日志路径

| 路径 |
| --- |
| |

请选择：**直接下发** / **下发并清洗**
```

段日志时，「日志类型」写成 `段日志（行首正则：xxx）`。没有行首正则就不要出这页。

采集目标按用户实际圈选填，**只填名称/IP，禁止填任何 ID**。出这页前必须已按 [host-target-resolve.md](host-target-resolve.md) 定位成功。

- 静态拓扑：目标类型 `静态拓扑`；对象填 IP，有主机名可写成 `IP（主机名）`；云区域填 **名称**（不要默认 0，也不要问用户要云区域 ID）。
- 动态拓扑：目标类型 `动态拓扑`；对象填 `集群名` 或 `集群名 / 模块名`；云区域留空。不要把模块拆成 IP 列表。
- 动态分组：目标类型 `动态分组`；对象填分组名；云区域留空。不要把分组成员拆成 IP 列表。

多台/多个节点就多行。不要把业务下全部主机写成目标。

「存储集群」必须填系统选定或用户指定的集群**名称**，禁止写「公共集群」。出表单前解析方法见 [mcp-workflow.md](mcp-workflow.md)。

## 2. 容器日志 · 确认采集配置

与主机共用上面那张配置表，但「接入类型」为 `容器日志采集`，**不要出现采集目标 / IP**。改用「采集配置范围」竖表。

配置表里的「日志路径」可以省略，路径写在每张范围竖表的「日志路径」行。

**禁止横表**（不要把对象/集群/命名空间等排成一行多列）。一条 `configs` 一张竖表；有多条就多张，标题编号为 `采集配置范围 1`、`采集配置范围 2`。Container 与 Node 可以同时出现。

## 3. 容器标准输出 · 确认采集配置

与容器日志同一张配置表，范围同样用**竖表**（禁止横表）。差别只有：

- 接入类型 = `容器标准输出采集`
- **没有日志路径行**（标准输出不采文件）
- 对象只圈 **Container**，不要写成 Node，也不要列 IP

## 4. 字段清洗结果（三种类型同一页）

仅当用户在确认表单选择「下发并清洗」，采集已创建，并且已经选定 json / 分隔符 / 正则之后，用这一页。三种接入类型版式相同。

先出清洗设置，再出**字段表格**。不要用段落罗列字段。

```markdown
## 字段清洗结果

| 配置项 | 内容 |
| --- | --- |
| 清洗模式 | JSON / 分隔符 / 正则 |
| 原始日志 | 保留 |
| 指定日志时间 | 日志上报时间 |
| 失败日志 | 保留 |

### 字段列表

| 字段名 | 类型 | 分词 | 值 |
| --- | --- | --- | --- |
| | string | 不分词 | |

确认后写入。
```

禁止出现「别名」列。无冲突时用上面四列。只要有字段与内置名冲突（如 `log`、`time`），把表头改成：

```markdown
| 字段名 | 字段冲突【调整为】 | 类型 | 分词 | 值 |
| --- | --- | --- | --- | --- |
| log | log_content | string | 分词 | |
| stream | | string | 不分词 | |
```

「字段冲突【调整为】」只填冲突行的入库名；无冲突行留空。写入接口仍用 `alias_name`，不要把「别名」展示给用户。

「值」有样例才填。样例优先用本采集已上报日志；没有日志才用用户手贴的。没有样例就留空，不要编。内置字段不要进这张表。
