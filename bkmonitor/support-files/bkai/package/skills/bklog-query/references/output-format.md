# 日志查询输出格式规范

本文档定义日志查询各阶段的标准输出格式，Agent 必须严格遵循。

---

## 一、通用规则

### 1.1 必须包含的元信息

每次输出必须包含以下元信息块：

```
查询路径：{路径类型}
{条件行...}
时间范围：{时间描述}
```

路径类型枚举：
- `索引集日志查询`
- `索引集日志查询 → 日志聚类分析`
- `索引集日志查询 → 字段分布分析`
- `索引集日志查询 → 日志上下文`
- `IaaS 容器日志查询`
- `IaaS 主机日志查询`
- `临时日志提取`
- `临时日志提取 → 文件发现`

### 1.2 禁止事项

- ❌ 不使用 emoji 表情
- ❌ 不使用过度装饰的分隔线
- ❌ 不输出冗余的解释性文字
- ❌ 不编造字段名或数据
- ❌ 不省略关键参数信息
- ❌ 不使用制表符、空格对齐或 Unicode 边框字符手动画表格

### 1.3 格式符号约定

| 符号 | 用途 |
| --- | --- |
| `━━━` | 区块标题分隔 |
| `>>>` `<<<` | 高亮目标行 |
| `✓` | 校验通过 |
| `✗` | 校验失败 |
| `⚠️` | 警告提示（仅此处允许 emoji） |

## 二、查询前输出格式

### 2.1 索引集选择提示

当用户未指定索引集时：

```
查询路径：索引集日志查询
业务 ID：{bk_biz_id}
查询条件：{query_string}
时间范围：{时间描述}

请选择索引集：
1. {索引集名称} (ID: {id})
2. {索引集名称} (ID: {id})
3. {索引集名称} (ID: {id})

请输入编号或索引集名称。
```

### 2.2 场景维度选择提示

IaaS 场景查询需要选择维度时：

```
查询路径：IaaS 容器日志查询
场景：{scene}
已选条件：
  - {维度1}: {值}
时间范围：{时间描述}

请选择 {待选维度名}：
1. {值1}
2. {值2}
3. {值3}

或输入 "all" 查询全部。
```

### 2.3 信息补充提示

用户意图不明确时：

```
请提供更多信息以完成日志查询：

1. 业务 ID（bk_biz_id）：{已知/待用户提供；当前不能按业务名查询}
2. 日志类型：
   - 索引集日志（需指定索引集）
   - K8s 容器日志（需指定集群、命名空间）
   - 主机日志（需指定主机 IP）
   - 未上报日志（需指定主机和路径）
3. 筛选条件：{已知/待确认}
4. 时间范围：{已知/默认最近1小时}

请补充上述信息。
```

## 三、查询结果输出格式

### 3.1 日志搜索结果

查询路径：{路径类型}
{索引集/场景信息}
查询条件：{query_string}
时间范围：{start_time} ~ {end_time}

原始返回数：{raw_total} 条
去重后数量：{deduplicated_total} 条
去重口径：{未去重/使用的字段组合}

日志样例（默认 3 条）：

#### 样例 1：原始日志

````text
{MCP 返回的第一条日志原文，逐字展示}
````

#### 样例 2-3：语义摘要

| 样例 | 时间 | 来源 | 语义摘要 |
| ---: | --- | --- | --- |
| 2 | {时间} | {来源} | {根据第二条日志生成的摘要} |
| 3 | {时间} | {来源} | {根据第三条日志生成的摘要} |

可用操作：
- {操作1}
- {操作2}

**字段规则**：
- 时间格式：`YYYY-MM-DD HH:mm:ss`
- 默认只展示 3 条；少于 3 条时按实际数量展示，不补造样例
- 第 1 条必须取查询结果中的第一条日志原文字段，保持 MCP 返回内容不变；不截断、不清洗、不重排字段、不添加语义总结
- 第 2、3 条可生成最多 80 字符的语义摘要，保留时间和来源；用户要求时提供对应完整原文
- 完全重复记录不得无说明地删除；必须同时展示原始返回数和去重后数量，并提供查看原始记录的入口
- 第 1 条即使是超长单行也完整展示；第 2、3 条超长时可摘要，但不得静默丢弃其原文访问入口

### 3.2 日志聚类结果

查询路径：索引集日志查询 → 日志聚类分析
索引集：{名称} (ID: {id})
聚类敏感度：{pattern_level}
过滤条件：{keyword}
时间范围：{时间描述}

聚类结果（共 {count} 种模式）：

| 模式 | 出现次数 | 占比 | 模式模板 | 代表日志 |
| --- | ---: | ---: | --- | --- |
| #1 | {n} | {percent}% | {pattern_template} | {sample_log} |
| #2 | {n} | {percent}% | {pattern_template} | {sample_log} |

可操作：输入模式编号查看原始日志

### 3.3 字段分布结果

查询路径：索引集日志查询 → 字段分布分析
索引集：{名称} (ID: {id})
分析字段：{field_name}
时间范围：{时间描述}

字段分布统计：

| {字段名} | 数量 | 占比 |
| --- | ---: | ---: |
| {值1} | {count} | {percent} |
| {值2} | {count} | {percent} |
| {值3} | {count} | {percent} |

总计：{total} 条

### 3.4 日志上下文结果

```
查询路径：索引集日志查询 → 日志上下文
定位日志：[{时间}] {日志摘要}
上下文范围：前后各 {n} 行

━━━ 上文（{n} 行）━━━
[{时间}] [{级别}] {日志内容}
[{时间}] [{级别}] {日志内容}
...

━━━ 目标日志 ━━━
>>> [{时间}] [{级别}] {日志内容} <<<

━━━ 下文（{n} 行）━━━
[{时间}] [{级别}] {日志内容}
[{时间}] [{级别}] {日志内容}
...
```

## 四、日志提取输出格式

### 4.1 安全校验结果

```
查询路径：临时日志提取
目标主机：{ip} 或 {count} 台

安全校验结果：
✓ 主机 {ip} 在授权范围内 (bk_host_id: {id})
✓ 路径 {path} 在允许列表中
✓ 文件类型 {ext} 允许提取

或：

✗ 路径 {path} 不在允许列表中
```

### 4.2 提取确认提示

**必须在创建任务前展示此确认框**：

```
提取确认：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
目标主机: {ip_list}
提取路径: {file_path}
过滤方式: {filter_description}
时间范围: {time_range}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 此操作将在目标主机执行文件提取任务。
是否确认创建提取任务？(是/否)
```

过滤方式描述：
- `不过滤（提取完整文件）`
- `提取最后 {n} 行`
- `按行号范围: {start}-{end}`
- `关键字匹配: {keyword}`
- `范围标记: {start} 到 {end}`

### 4.3 任务状态输出

```
任务已创建
任务 ID: {task_id}
状态: {state}

正在等待任务完成...
```

状态值：`pending` | `running` | `downloadable` | `failed` | `expired`

### 4.4 任务完成输出

```
任务完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务 ID: {task_id}
状态: downloadable
目标: {host}:{path}
{过滤信息}
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如需下载，请告诉我。
```

### 4.5 文件发现结果

查询路径：临时日志提取 → 文件发现
目标主机：{ip}
搜索路径：{path}
递归搜索：{是/否}

文件发现结果：

| 相对路径 | 大小 | 修改时间 |
| --- | ---: | --- |
| {filename} | {size} | {mtime} |
| {filename} | {size} | {mtime} |
| {subdir}/{filename} | {size} | {mtime} |
| {subdir}/{filename} | {size} | {mtime} |

共发现 {count} 个文件，总大小约 {total_size}

请选择要提取的文件。

## 五、异常输出格式

### 5.1 查询无结果

```
查询路径：{路径类型}
{查询条件信息}
时间范围：{时间描述}

原始返回数：0 条
去重后数量：0 条
去重口径：未去重

未找到匹配的日志。建议：
1. {建议1}
2. {建议2}
3. {建议3}

是否调整查询条件？
```

### 5.2 安全拦截

```
⚠️ 安全校验失败

{拦截原因描述}

{允许范围说明}

请修改后重试。
```

### 5.3 查询跨度超限

```
⚠️ 查询跨度超过限制

请求时间范围: {requested}
最大允许跨度: 1 天

建议：
1. 分批查询（每批 ≤24 小时）后合并
2. 缩小时间范围

是否按方案 1 执行分批查询？(是/否)
```

### 5.4 业务/索引集不存在

```
未找到 {类型} "{name}"。

可用的 {类型}：
1. {name1} (ID: {id1})
2. {name2} (ID: {id2})
...

请选择或输入正确名称。
```

### 5.5 接口错误

```
查询失败

错误类别: {索引集不存在/字段不存在/聚类未配置/参数错误/鉴权失败/提取任务失败/提取任务过期}
错误信息: {面向用户的归一化说明}
request_id: {request_id}

已完成步骤：
- {step1}: 成功
- {step2}: 失败

建议下一步: {suggestion}
```

默认不展示嵌套下游异常、内部 Resource 名称或多层错误码；排障需要时再提供原始错误摘要。

## 六、表格格式规范

### 6.1 简单表格

用于字段分布、统计结果：

| 列标题1 | 列标题2 | 列标题3 |
| --- | ---: | --- |
| 数据1 | 数据2 | 数据3 |
| 数据4 | 数据5 | 数据6 |

表格必须直接使用 Markdown 语法，不能放进代码块；禁止用制表符、空格对齐或 Unicode 边框字符手动画表格。长字段导致表格难以阅读时，降级为键值列表。

### 6.2 列表格式

用于选择项、操作列表：

```
1. {选项1}
2. {选项2}
3. {选项3}
```

或带说明：

```
1. {名称} (ID: {id}) - {说明}
2. {名称} (ID: {id}) - {说明}
```

### 6.3 键值对格式

用于元信息展示：

```
{键1}: {值1}
{键2}: {值2}
{键3}: {值3}
```

或带层级：

```
路由条件：
  - {维度1}: {值1}
  - {维度2}: {值2}
内容过滤：{query_string}
```

## 七、场景输出模板速查

| 场景 | 必须包含 | 模板参考 |
| --- | --- | --- |
| 索引集选择 | 业务ID、查询条件、索引集列表 | 2.1 |
| 日志搜索结果 | 路径、条件、时间、原始/去重数量、3 条样例、可用操作 | 3.1 |
| 日志聚类 | 敏感度、模式列表（含次数占比） | 3.2 |
| 字段分布 | 字段名、分布表格、总计 | 3.3 |
| 日志上下文 | 定位信息、上下文内容、目标高亮 | 3.4 |
| 提取确认 | 主机、路径、过滤、警告、确认提示 | 4.2 |
| 提取完成 | 任务ID、状态、下载提示 | 4.4 |
| 文件发现 | 主机、路径、文件树、统计 | 4.5 |
| 无结果 | 条件回显、建议列表 | 5.1 |
| 安全拦截 | 拦截原因、允许范围 | 5.2 |
