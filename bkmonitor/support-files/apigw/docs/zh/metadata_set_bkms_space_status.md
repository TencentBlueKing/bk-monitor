### 功能描述

设置当前租户下 BKMS 空间的启停状态。仅支持 `space_type_id=bkci` 且 `space_id` 以 `bkms-` 开头的空间。调用应用需申请本资源权限。

### 请求参数

| 字段 | 类型 | 必选 | 描述 |
|---|---|---|---|
| space_uid | str | 是 | 空间唯一标识，格式为 `bkci__bkms-<项目>` |
| status | str | 是 | `disabled` 停用，`normal` 启用 |

### 请求参数示例

```json
{
    "space_uid": "bkci__bkms-example",
    "status": "disabled"
}
```

### 响应参数

| 字段 | 类型 | 描述 |
|---|---|---|
| result | bool | 请求是否成功 |
| code | int | 返回状态码 |
| message | str | 描述信息 |
| data | dict | 写入后的空间标识和状态 |

### 响应参数示例

```json
{
    "result": true,
    "code": 200,
    "message": "OK",
    "data": {
        "space_uid": "bkci__bkms-example",
        "status": "disabled"
    }
}
```

### 生效说明

- 成功表示空间状态已写入，重复设置同一状态可安全重试。范围不符、空间不存在或不属于当前租户时返回错误，不修改空间。
- 停用后，空间选择器与“我的空间”隐藏该空间，“全部空间”保留并显示停用状态；空间列表有进程缓存，最长约 10 分钟生效。
- 策略在下一轮全量缓存刷新后退出执行，正常刷新周期约 6 分钟；Go 告警引擎还可能保留执行最长 10 分钟。策略原有开关、数据采集、配置和历史数据保留。
- 存量策略告警沿用现有策略停用时的关闭与通知规则。重新启用仅恢复原本启用的策略，可能沿用旧 checkpoint 补拉停用期间的数据。
- 两次设置均发生在缓存刷新前时，以最终状态为准，可能没有经过实际停用或告警关闭。
